# v2.0.1 Price Registry + Medallion Source Verification

**Date:** 2026-08-14  
**Status:** VERIFIED against current primary documentation

## Databricks evidence

1. `system.compute.warehouse_events` records SQL Warehouse start/stop/run/scale events and `cluster_count`.
2. Current Databricks SQL Warehouse sizing documentation publishes the classic/pro driver instance type and worker count for each warehouse size; all workers are documented as `i3.2xlarge`. The documentation also warns the mapping may vary by product/region/workspace availability and must therefore be version/release revalidated.
3. `system.billing.usage` provides Databricks usage and `usage_metadata.warehouse_id`; current schema also exposes `usage_metadata.node_type` for non-serverless/all SQL warehouses where populated.
4. Serverless SQL Warehouse infrastructure is Databricks-managed and must not inherit the customer EC2 price-registry model.
5. Databricks recommends the medallion Bronze/Silver/Gold data-design pattern. The product adds Control and ML companion schemas.

Primary references:

- https://docs.databricks.com/aws/en/admin/sql/serverless
- https://docs.databricks.com/aws/en/lakehouse/medallion

## AWS pricing evidence

- AWS Price List Query/Bulk APIs are suitable for product/price lookup and planning/cost analysis.
- AWS Price List Query does not provide Savings Plan prices; without CUR/chargeback evidence, commitment/cash-realizable actuals remain unavailable.
- Spot is dynamic; `DescribeSpotPriceHistory` provides historical Spot prices and is the appropriate source for a versioned Spot estimate.

Primary references:
- https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/price-changes.html
- https://docs.aws.amazon.com/AWSEC2/latest/APIReference/API_DescribeSpotPriceHistory.html
